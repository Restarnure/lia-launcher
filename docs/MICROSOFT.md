# Вхід Microsoft у ЛІЇ

Minecraft пускає до свого API тільки програми, які схвалила Mojang. Тому лаунчеру потрібен свій застосунок в Azure і разове схвалення від Mojang. Після цього ID вшивається в лаунчер, і гравці просто тиснуть «Увійти через Microsoft».

У ЛІЇ це вже зроблено: застосунок «ЛІЯ» зареєстрований, ID вшитий, заявку в Mojang подано 25.10.2026. Нижче описано, як це робиться, якщо колись доведеться повторити.

Брати чужий Client ID (наприклад, офіційного лаунчера) не можна: так твоя програма видає себе за чужу.

## 1. Застосунок в Azure

Самого акаунта Microsoft мало: без каталогу Azure не дасть створити застосунок. Каталог з'являється разом з безкоштовною підпискою на <https://azure.microsoft.com/free>. Там попросять телефон і картку для перевірки, але за реєстрацію застосунку гроші не знімаються.

1. Відкрий <https://portal.azure.com>, знайди вгорі **App registrations** і натисни **New registration**.
2. Заповни:
   - **Name:** `ЛІЯ`. Цю назву гравці побачать на сторінці входу Microsoft.
   - **Supported account types:** *Personal Microsoft accounts only*.
   - **Redirect URI:** платформа *Public client/native (mobile & desktop)*, адреса `https://login.microsoftonline.com/common/oauth2/nativeclient`.
3. Натисни **Register**.
4. На сторінці застосунку скопіюй **Application (client) ID** і **Directory (tenant) ID**.
5. У розділі **Authentication** знайди **Allow public client flows**, увімкни і збережи.

Секрет і дозволи API не потрібні. ЛІЯ працює як публічний клієнт, а дозвіл `XboxLive.signin` запитує під час входу.

## 2. Заявка в Mojang

1. Відкрий форму <https://aka.ms/mce-reviewappid>.
2. Вкажи email (той самий, що в Azure), обидва ID, назву і посилання на репозиторій. В обґрунтуванні коротко напиши, що це за лаунчер і навіщо йому вхід.
3. Відправ. Заявки дивляться раз на тиждень, відповідь приходить на пошту. Слати форму вдруге не треба, швидше від цього не буде.

Mojang не схвалює програми, які дають грати без купленої гри. Тому в ЛІЇ офлайн-нік можна додати тільки після входу через Microsoft з ліцензією, і про це варто написати в заявці.

Поки схвалення немає, вхід у Microsoft пройде, але на останньому кроці Minecraft відповість 403, і ЛІЯ напише, що Mojang ще не схвалила застосунок.

## 3. Як вшити ID

Можна вписати його в `src-tauri/src/settings.rs`, у `const BUILT_IN`, і випустити оновлення. Або задати змінну `LIA_MS_CLIENT_ID=<ID>` перед `node scripts/release.mjs …`.

Щоб перевірити інший ID без релізу, запусти `npm run tauri dev`: у налаштуваннях з'явиться блок «Для розробника», куди його можна вписати. У звичайній збірці цього блоку немає.

## Як працює вхід

1. ЛІЯ відкриває вікно з офіційною сторінкою входу Microsoft (OAuth 2.0 з PKCE, тенант `consumers`).
2. Після входу Microsoft перекидає на `…/nativeclient?code=…`, і ЛІЯ забирає код. У браузер він не потрапляє.
3. За кодом ЛІЯ отримує токени, далі Xbox Live, XSTS, токен Minecraft і профіль гравця. Якщо гри на акаунті немає, вхід зупиняється з помилкою.
4. Токени зберігаються в `%APPDATA%\.lia\accounts.dat`, зашифровані ключем твого користувача Windows (DPAPI), і тихо оновлюються перед запуском гри.
