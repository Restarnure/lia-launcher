# ЛІЯ

Український лаунчер для Minecraft: Java Edition. Реклами й стеження немає. Гру, бібліотеки та Java лаунчер качає з офіційних серверів Mojang, а моди з Modrinth.

## Що вміє

- Ставить будь-яку версію гри, від b1.7.3 до 26.x і знімків.
- Fabric, Quilt, Forge (від 1.7.10) і NeoForge (1.21.1 і 26.x) ставляться в один клік.
- Сам підбирає й ставить потрібну Java (офіційні 8, 17, 21 і 25 від Mojang).
- Збірки: у кожної свої моди, світи й налаштування (пам'ять, Java, аргументи JVM, розмір вікна).
- Каталог Modrinth з модами, модпаками, ресурспаками й шейдерами. Показує тільки те, що підходить до збірки, сам довантажує залежності, оновлює встановлені моди. Файл `.mrpack` можна просто перетягнути у вікно.
- Акаунти Microsoft (ліцензія, скіни, плащі) і офлайн-ніки. Офлайн-нік можна додати тільки після входу через Microsoft з купленою грою. Вхід іде через офіційну сторінку Microsoft, а токени шифруються ключем твого користувача Windows (DPAPI).
- Скіни: бібліотека з 3D-мініатюрами, можна додати з файлу, за ніком гравця або перетягнувши PNG. Є стандартні скіни Mojang і плащі, модель (класична чи тонка) визначається сама.
- Оновлюється сам: показує, що змінилось, і перезапускається. Якщо гра в цей час запущена, вона не закриється. Оновлення підписані, підробку лаунчер не поставить.
- Сервер Shotam на головній: видно онлайн і MOTD, а кнопка «Грати на Shotam» сама створює збірку потрібної версії з голосовим чатом і заходить на сервер.
- Консоль гри з пошуком і підсвіткою. Якщо гра впала, лаунчер пояснює чому: не вистачило пам'яті, не та Java, несумісні моди, драйвер відеокарти тощо.
- Швидкий вхід у світ чи на сервер (з 1.20). Світи й скріншоти збірки видно прямо в лаунчері, а видалене йде в кошик.
- Переїзд з іншого лаунчера: світи, ресурспаки, шейдери, моди, налаштування й сервери переносяться з будь-якої теки `.minecraft` у нову збірку. Оригінал при цьому не змінюється.
- У кожну нову збірку додає Shotam у список серверів, якщо списку ще немає. Вимикається разом з карткою на головній.
- Легкий: інсталятор менше 4 МБ, сам лаунчер близько 9 МБ і майже не їсть пам'ять, поки йде гра.
- Без інтернету теж працює, якщо гру вже завантажено. Якщо перезапустити лаунчер, поки йде гра, він її підхопить, і ту саму збірку двічі не запустиш.
- Інтерфейс українською та англійською.

## Встановлення

Завантаж `LIA_<версія>_x64-setup.exe` з [релізів](https://github.com/Restarnure/lia-launcher/releases) і запусти. Права адміністратора не потрібні, далі лаунчер оновлюється сам.

Усе лежить у `%APPDATA%\.lia` (теку гри можна змінити в налаштуваннях):

```
.lia/
  launcher.json        налаштування
  accounts.dat         акаунти (зашифровані DPAPI)
  skins/               бібліотека скінів
  instances/<id>/      збірки: instance.json + .minecraft/ (моди, світи…)
  versions/ libraries/ assets/   спільні файли гри, як у .minecraft
  runtimes/            Java від Mojang
```

## Розробка

Треба Node.js 20+, Rust (stable), Visual Studio Build Tools з «Desktop development with C++» і WebView2 (у Windows 11 він уже є).

```bash
npm install
npm run tauri dev
```

Інсталятор збирається скриптом випуску, бо він підписує оновлення ключем (див. нижче):

```bash
node scripts/release.mjs 1.0.0
```

Якщо ключа немає, можна зібрати тестовий інсталятор. Для автооновлень він не годиться:

```bash
npm run tauri build -- --config "{\"bundle\":{\"createUpdaterArtifacts\":false}}"
```

Тести ядра, без мережі:

```bash
cd src-tauri && cargo test --lib
```

Справжній запуск гри. Качає близько 1 ГБ у `%TEMP%\lia-e2e`, вікна гри на кілька секунд з'являться на екрані:

```bash
cd src-tauri && LIA_E2E="26.3,1.12.2,fabric:1.21.11,forge:1.20.1,neoforge:1.21.1" cargo test --test e2e -- --ignored --nocapture
```

Змінні середовища для тестів і портативного режиму: `LIA_HOME` (тека налаштувань) і `LIA_DATA` (тека даних гри).

## Випуск оновлення

Одна команда піднімає версію, збирає підписаний інсталятор і викладає реліз на GitHub. Звідти його й заберуть лаунчери гравців:

```bash
node scripts/release.mjs 1.0.1 "Що нового (markdown)" --publish
```

Без `--publish` скрипт тільки збирає `release/<версія>/` (інсталятор і `latest.json`), щоб спершу перевірити.

Лаунчери шукають оновлення тут: `https://github.com/Restarnure/lia-launcher/releases/latest/download/latest.json`.

Приватний ключ підпису лежить у `%USERPROFILE%\.tauri\lia-updater.key`, відкритий прописаний у `tauri.conf.json`. Зроби копію ключа: без нього вже встановлені лаунчери не приймуть жодного оновлення. У репозиторій ключ не комітиться.

## Вхід Microsoft

Mojang пускає до Minecraft API тільки схвалені застосунки Azure. ЛІЯ свій застосунок має, його ID уже вшитий у лаунчер (`BUILT_IN` у `src-tauri/src/settings.rs`), тож гравцям нічого налаштовувати не треба. Як це все робиться з нуля, описано в [docs/MICROSOFT.md](docs/MICROSOFT.md).

## Shotam

Закріплений сервер описаний у `src-tauri/src/servers.rs` (`builtin()`): адреса, версія гри, модлоадер і моди з Modrinth. Щоб міняти це без нового релізу, достатньо викласти на сайті `https://shotam.today/launcher.json`:

```json
{
  "id": "shotam",
  "name": "Shotam",
  "address": "shotam.today",
  "port": 25565,
  "mcVersion": "1.21.11",
  "loader": "fabric",
  "mods": ["simple-voice-chat"],
  "website": "https://shotam.today",
  "descriptionUk": "Український сервер виживання…",
  "descriptionEn": "Ukrainian survival server…"
}
```

Коли сервер перейде на нову версію, збірка «Shotam» у гравців оновиться сама, щойно вони натиснуть «Грати на Shotam».

## Як усе влаштовано

- `src-tauri/src/`: ядро на Rust (Tauri 2): `mojang/` (версії, правила, бібліотеки, ресурси, Java), `loaders.rs`, `launch.rs` (аргументи, запуск, лог), `modrinth.rs`, `content.rs`, `accounts.rs`, `skinlib.rs` (бібліотека скінів), `servers.rs`, `app.rs` (команди для інтерфейсу).
- `src/`: інтерфейс на React і TypeScript: `pages/`, `components/`, `lib/` (стан, переклади, оновлення, піксельні блоки, MOTD, 3D-мініатюри скінів).
- `scripts/release.mjs`: випуск оновлення.
