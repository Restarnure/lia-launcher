# ЛІЯ

Лаунчер для Minecraft: Java Edition. Гра, бібліотеки й Java качаються з серверів Mojang, моди з Modrinth.

## Що вміє

- Усі версії від b1.7.3 до 26.x, включно зі знімками.
- Fabric, Quilt, Forge (з 1.7.10), NeoForge (1.21.1, 26.x).
- Java під версію гри ставиться сама: 8, 17, 21 або 25 від Mojang.
- Окремі збірки зі своїми модами, світами, пам'яттю, Java, аргументами JVM і розміром вікна.
- Каталог Modrinth: моди, модпаки, ресурспаки, шейдери. Показує лише сумісне зі збіркою, ставить залежності, оновлює моди. `.mrpack` можна перетягнути у вікно.
- Акаунти Microsoft і офлайн-ніки. Токени шифруються через DPAPI.
- Бібліотека скінів з 3D-мініатюрами: з файлу, за ніком або перетягуванням PNG. Є стандартні скіни Mojang і плащі, модель (класична чи тонка) визначається автоматично.
- Автооновлення з перевіркою підпису. Запущену гру оновлення не закриває.
- Закріплений сервер на головній: онлайн, MOTD і кнопка, яка створює збірку під сервер і заходить на нього. Цей сервер також додається в список серверів нових збірок, якщо списку ще немає. Вимикається в налаштуваннях.
- Консоль гри з пошуком і підсвіткою. Після краша лаунчер пробує визначити причину: пам'ять, Java, несумісні моди, драйвер відеокарти.
- Швидкий вхід у світ або на сервер (1.20+). Світи й скріншоти збірки видно в лаунчері, видалене йде в кошик.
- Імпорт з `.minecraft` інших лаунчерів: світи, моди, ресурспаки, шейдери, налаштування, сервери.
- Інсталятор менше 4 МБ, лаунчер близько 9 МБ.
- Працює без інтернету, якщо гру вже завантажено. Після перезапуску підхоплює запущену гру, одну збірку двічі не запустити.
- Редактор скінів: малювання прямо на 3D-моделі або на розгортці, дзеркало ліво/право, два шари, заливка грані, тіні й шум, скасування дій.
- ЛІЯ ID: акаунт лаунчера, окремий від ігрового, з підтвердженням пошти. Друзі й статус «у грі» працюють і з піраткою, і з ліцензією.
- Спільні світи: відкрий світ для LAN, і друзі зайдуть у нього через ретранслятор ЛІЇ. Порти й роутер налаштовувати не треба. З ліцензією світ для всіх відкриває кнопка «З друзями».
- Збірками можна ділитися з друзями: підписка, оновлення в один клік, світи й налаштування при оновленні лишаються.
- Масштаб інтерфейсу і верстка під широкі монітори.
- Інтерфейс українською та англійською.

## Встановлення

Інсталятор `LIA_<версія>_x64-setup.exe` лежить у [релізах](https://github.com/Restarnure/lia-launcher/releases). Права адміністратора не потрібні.

Дані зберігаються в `%APPDATA%\.lia`, теку гри можна змінити в налаштуваннях:

```
.lia/
  launcher.json        налаштування
  accounts.dat         акаунти (зашифровані DPAPI)
  skins/               бібліотека скінів
  instances/<id>/      збірки: instance.json + .minecraft/ (моди, світи…)
  versions/ libraries/ assets/   спільні файли гри, як у .minecraft
  runtimes/            Java від Mojang
```

Збірка з коду й випуск оновлень: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Приватність

ЛІЯ не збирає статистики й нічого не надсилає без потреби. Мережа потрібна лише для того, що ви робите в лаунчері:

- **Mojang і Microsoft:** файли гри, Java, новини, вхід в акаунт Microsoft, скіни й плащі.
- **Modrinth:** каталог і завантаження. Щоб показати назви й оновлення модів, доданих вручну, лаунчер надсилає Modrinth хеші їхніх файлів.
- **Fabric, Quilt, Forge, NeoForge:** версії модлоадерів і їхні файли.
- **GitHub:** перевірка оновлень лаунчера й завантаження authlib-injector для гри через ЛІЯ ID.
- **shotam.today:** картка закріпленого сервера на головній, вимикається в налаштуваннях.
- **lia.starnure.dev (сервер ЛІЇ):** при запуску лаунчер повідомляє лише свою версію, щоб перевірити, чи вона не застаріла. Якщо ви увійшли в ЛІЯ ID, сервер зберігає нік, пошту, хеш пароля, друзів і пристрої, показує друзям ваш статус у грі й пропускає їх у світ, який ви відкрили.
